# Coin Detection using PyTorch

## Background

This is our semester project for the subject Neural Network and Memristive Hardware Accelerators at TU Dresden named Coin Detection using PyTorch. This project is supervised by Prof. [Steffen Seitz](emailto:steffen.seitz@tu-dresden.de)

## Task 

Building an AI-based system that is able to detect different euro coins based on their ultrasound noise.
